## Decision 1:
Date: 11-12-26

- OpenF1 vs FastF1:

    - FastF1 Pros:
        - Race data from 2018 onward
        - Clean formatted data
    - FastF1 Cons:
        - Need a login in token that can expire and cause issues running the program
        - Clean formatted data offers less learning
        
    - OpenF1 Pros: 
        - Free to use
        - Has an explicit non-commercial license
        - Messy data allowing for more learning
    - OpenF1 Cons:
        - Race data is only 2023 onwards

    - Choice: I decided to use OpenF1 for data because it would allow for me to learn how to deal with messy and unformatted data which is something I am much more likely to face in a real work situation.
